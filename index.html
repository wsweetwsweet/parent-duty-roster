從 Google 試算表匯入

  1. 在 Google 試算表按右上「共用」→ 一般存取權改成「知道連結的任何人」→ 角色「檢視者」。
  2. 複製網址列的整段網址，貼到下面。（也可以貼「檔案 → 分享 → 發布到網路」產生的網址）
  3. 欄位名稱要有「學生姓名／家長稱呼／到課星期」，跟 Excel 範本一樣。

時段設定

這一整張卡片的設定只套用到目前選的時段，兩個時段各自獨立。 時間只影響匯出到日曆的活動長度，不影響排班。「每天需要」設為 0 等於停用這個時段。

不排班的日期（假日／段考／不上課的日子）

連線設定（Firebase，多人即時共用）

  1. 到 Firebase 主控台 用你的 Google 帳號新增專案。
  2. 左側「資料庫和儲存空間 → Firestore」→ 建立資料庫 → 位置選 asia-east1 → 測試模式。
  3. 齒輪「專案設定 → 一般」→ 最下面「您的應用程式」→ 點 </> 註冊網頁應用程式，會出現 firebaseConfig = { ... }。
  4. 把那整段貼到下面，按「儲存並連線」。
  5. 回到 Firestore 的「規則」分頁，貼上 repo 裡 firestore.rules 的內容並發布。
