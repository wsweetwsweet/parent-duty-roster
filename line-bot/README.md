# 家長值班 LINE 機器人

把機器人加進 LINE 群組後：

- 群組裡有人輸入 **今天／明天／本週／下週／班表／說明**，機器人就會回覆班表（回覆不算 LINE 免費額度）。
- **每週五晚上 8 點左右**，機器人會自動把下週一到五的班表發到群組。整週放假的話就不發。
- 其他聊天內容機器人一律不回。

班表資料直接讀網頁用的 Firebase，網頁上改了，機器人馬上就會查到新的，不用另外同步。

---

## 事前準備：Firebase 專案 ID 和 API 金鑰

到 [Firebase 主控台](https://console.firebase.google.com/) → 選你的專案 → 左上齒輪「專案設定」→「一般」頁籤往下找「你的應用程式」，記下：

- `projectId`（專案 ID）
- `apiKey`（網頁 API 金鑰）

這兩個就是網頁「設定」頁裡貼過的那段 Firebase 設定中的同名欄位。

---

## 步驟 1：建立 LINE 官方帳號

1. 打開 [LINE Official Account Manager](https://manager.line.biz/)，用你的 LINE 帳號登入，按「建立 LINE 官方帳號」。
2. 帳號名稱可以取「家長值班小幫手」。類別隨便選一個接近的，例如「教育」。不用送審核。
3. 建好後進入帳號，點右上「**設定**」：
   - 「帳號設定」→「功能切換」→ **加入群組或多人聊天室：選「接受邀請加入群組或多人聊天室」**，然後儲存。
   - 左側「**Messaging API**」→ 按「啟用 Messaging API」→ 建立一個服務提供者（名稱隨意，例如自己的名字）→ 確定。
4. 點右上「**回應設定**」：
   - **自動回應訊息：關閉**（不然它會在群組亂回罐頭訊息）
   - **Webhook：開啟**
   - 加入好友的歡迎訊息可以保留或關閉，都可以

## 步驟 2：取得 Channel access token

1. 打開 [LINE Developers](https://developers.line.biz/console/)，用同一個 LINE 帳號登入。
2. 點剛剛建立的服務提供者 → 點機器人的 channel → 「**Messaging API**」頁籤。
3. 拉到最下面「Channel access token (long-lived)」→ 按「**Issue**」→ 複製那串很長的文字。

> ⚠️ 這串 token 等於機器人的密碼，不要貼到群組或公開的地方。

## 步驟 3：建立 Google Apps Script

1. 打開 [script.google.com](https://script.google.com/) → 「新專案」，把專案名稱改成「家長值班機器人」。
2. 把編輯器裡原本的 `function myFunction() {...}` 全部刪掉，貼上這個資料夾裡 [Code.gs](Code.gs) 的完整內容，按 💾 儲存。
3. 左側齒輪「**專案設定**」：
   - **時區**：選「(GMT+08:00) 台北」
   - 拉到最下面「**指令碼屬性**」→「新增指令碼屬性」，加入這三個（屬性名稱要完全一樣，全大寫、不要有空白或引號）：

     | 屬性 | 值 |
     |---|---|
     | LINE_TOKEN | 步驟 2 複製的 token |
     | FIREBASE_PROJECT_ID | Firebase 的 projectId |
     | FIREBASE_API_KEY | Firebase 的 apiKey |

   - 儲存。
4. 回到編輯器，上方函式選單選 **`預覽下週提醒`** → 按「執行」。
   - 第一次會要求授權：選你的 Google 帳號 →「進階」→「前往 家長值班機器人（不安全）」→「允許」。這是因為程式是你自己寫的，沒有經過 Google 審核，屬於正常情形。
   - 下方「執行記錄」會出現下週班表的文字，看得到就代表讀 Firebase 成功。

## 步驟 4：部署成網址，接到 LINE

1. Apps Script 右上「**部署**」→「新增部署作業」→ 齒輪選「**網頁應用程式**」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
2. 回到 LINE Developers →「Messaging API」頁籤 →「**Webhook settings**」：
   - Webhook URL：貼上剛剛的網址 → Update
   - **Use webhook：打開**
   - 旁邊的「Verify」按鈕可能會顯示錯誤（Google 的網址會轉址），**可以忽略**，實際在群組測試能用就好。

## 步驟 5：設定每週五自動提醒

回到 Apps Script 編輯器，上方函式選單選 **`建立每週提醒`** → 執行。執行記錄出現「已建立：每週五 20:00 左右推播下週班表」就完成了。Google 的定時器會在 20:00–21:00 之間執行，不一定準時在 20:00 整。

## 步驟 6：把機器人拉進群組

1. LINE Official Account Manager 首頁 →「加入好友」工具，用手機掃 QR code，把機器人加為好友。
2. 到家長群組 → 右上選單 →「邀請」→ 選機器人。
3. 機器人進群後會打招呼，並自動記下這個群組，之後每週的提醒就發到這裡。
4. 在群組輸入「**本週**」試試看。

可以同時綁定多個群組：機器人被拉進哪個群組，那個群組就會加入每週提醒的清單。已經在群組裡的話，在該群組輸入「**綁定群組**」即可加入；不想再收到提醒，輸入「**取消綁定**」。機器人被踢出群組時會自動移出清單。

## 之後要修改程式

改完 Code.gs 後要重新部署，LINE 才會用到新版：**部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**。網址不會變，不用回 LINE 改設定。

## 免費額度

- 回覆關鍵字：**不算額度**，怎麼問都免費。
- 每週推播：發到群組時**按人數計算**。群組 10 人的話，一個月約 4–5 次 × 10 人 ≈ 50 則，遠低於免費方案每月 200 則。
- 可以在 LINE Official Account Manager →「分析」→「訊息則數」查看用量。

## 已知限制

- 每週提醒目前在訊息最前面 **@All**（程式最上方 `MENTION_ALL` 設為 `true`）。要 @ 個別家長需要先知道每位家長的 LINE userId。
- 機器人會自動記下在群組發言過的人（userId 和 LINE 暱稱）。在 Apps Script 執行 `查看發言者名單` 就能在執行記錄看到名單。只有機器人在群組、webhook 開著期間的發言才收得到。
- Apps Script 讀不到 LINE 送來的簽章，所以無法驗證請求確實來自 LINE。不過回覆必須用 LINE 給的一次性代碼，別人就算知道網址也沒辦法用機器人亂發訊息。Webhook 網址還是不要公開比較好。
